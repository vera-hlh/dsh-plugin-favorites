# DSH 收藏夹

在 DeepSeek Harness 的会话里收藏一条回复、一整轮对话、一段选中的文字，或一个文件——加标签、写备注，以后一键跳回来。

会话一长，你需要的那段回答就被上百次工具调用淹没了。收藏夹把这些位置收在一个面板里，按工作区分组，可按标签、类型、会话、文字检索。

中文文档对应 `README.md` 的英文版。

## 功能

- **四种范围**：仅回复 / 提问+回复 / 选中文字 / 文件。
- **一个面板**（左侧栏「收藏夹」）：工作区分组、标签筛选、类型筛选、会话筛选、全文搜索。
- **跳回定位**：点收藏打开会话，滚动到收藏的文字处并用琥珀色高亮标出。
- **备注与标签**：每条都能写备注、加标签；标签可直接从已有标签里点选，避免同义不同名。
- **只存本机**：数据保存在当前 profile 的数据目录，不上传任何地方。
- **对 agent 可见**：注册了 `favorites` 工具（`list` / `add` / `remove`），会话可以按你的要求帮你收藏。

## 入口

| 位置 | 说明 |
|---|---|
| 每条助手回复的操作行 | 书签图标 |
| 选中文字后 | 浮出的「加入收藏」按钮 |
| 左侧栏 | 「收藏夹」 |
| 收藏夹面板工具栏 | 「收藏文件」 |

书签图标有三种状态：空心（未收藏）、半透明实心（该回复所属回合已被收藏）、实心（已收藏）。

## 四种范围

| 范围 | 存什么 | 跳转落在哪 |
|---|---|---|
| 仅回复 | 回复正文 | 回复第一行 |
| 提问+回复 | 该轮提问与回复 | 该轮提问处 |
| 选中文字 | 你选中的那段文字 | 那段文字（并高亮） |
| 文件 | 文件路径（可带行号区间）与所在消息 | 消息处，由你点开文件链接 |

## 跳转行为

跳转会在转写区里搜索保存的文字，把它滚动到转写区上方附近，并用琥珀色高亮几秒。

- 打开会话、加载历史、改变窗口大小之后都会继续校正，所以改屏也能落对位置。
- 你一旦主动操作（滚动、点击、触摸、按键），立刻停止校正并清除高亮。
- 如果目标消息不在已加载窗口内，会先自动向上翻页再定位。

## 文件收藏

除了会话内容，面板里还能放文件书签：路径 + 可选行号区间，和工作区内容分在同一视图，支持面板内预览与复制路径。agent 也能创建。

## 安装

本包是 DSH bundle：没有依赖、没有安装脚本、不需要构建。

**从 npm 安装（用 `dsh` CLI，需要 Node.js ≥ 24.9）**：

```powershell
npx @deepseek-ai/dsh@0.2.2-rc.5 plugin --profile desktop add dsh-plugin-favorites
```

把 `desktop` 换成你实际使用的 profile 名。命令会把包装进该 profile；装完重启一次 DSH，让前端 bundle 加载。

**从本地目录安装**（开发时更方便）：

```powershell
git clone https://github.com/vera-hlh/dsh-plugin-favorites.git
```

然后在 DSH 打开「插件」，把克隆下来的目录添加为插件、启用，并重启一次。以链接方式安装时，改动源码后下次重载即生效。

需要带 Web 客户端的 DSH（`@deepseek-ai/dsh-client-ui-conversation`、`-sidebar`、`-layout`）；插件会注册到回复操作行、左侧栏和浮层。

## 数据与隐私

- 收藏保存在 `<DSH_HOME>/profiles/<profile>/data/favorites.json`，每次写入前会生成 `favorites.backup.json`。
- 浏览器端在 `localStorage` 里保留一份镜像，加载时与文件合并。
- 全部数据只在本机：插件不发任何网络请求，收藏内容也不会自动进入模型上下文。
- 面板里的**导出 / 导入**用于跨机器搬运：导出写一个 JSON 文件，导入会合并（同 id 保留较新的修改，新 id 直接加入）。
- HTTP 接口只响应 DSH 自己的页面（同源，或桌面版的 dsh-app:// 外壳），其它网页无法读写这些数据。
- 数据按 profile 存放，切换 profile 就是另一套收藏。

## 已知限制

- **1.0.0 之前创建的「提问+回复」收藏**没有保存提问文字，跳转可能落在回复而不是提问；重新收藏一次即可修正。
- 跳转只能定位到转写区能加载的消息；自动翻页最多约十页。
- 每条最多 8 个标签，每个标签最多 40 字符。
- 定位依据渲染后的文字，若摘录的排版被大幅拆分（例如大量行内样式），可能退回到较粗的定位方式。

## 关闭或卸载

在「插件」中禁用即可移除按钮、浮动按钮、面板和 agent 工具。数据文件仍保留，重新启用后收藏全部回来。

## 开发

| 文件 | 作用 |
|---|---|
| `index.js` | 宿主侧：基于 profile 数据文件的 HTTP 路由、`favorites` 工具 |
| `client.js` | Web 侧：插槽注册、面板、弹窗、跳转与高亮 |
| `cordis.patch.yml` | 插入插件行的 bundle 补丁 |
| `locale/*.json` | 插件管理器显示的元数据 |
| `docs/` | 详情文档与功能图 |

改动宿主侧后，在「插件」里重新启用即可生效；改动前端侧需要重启应用（或重新构建客户端插件）。
